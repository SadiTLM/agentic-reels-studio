03 / Arquitectura del Sistema

            
Cómo opera la automatización de punta a punta

          

          

            Separamos generación, auditoría independiente y aprobación humana para que ningún agente publique ni toque producción a ciegas.
          

        


        

          
          

            

              01 / TENDENCIAS
              
last30days + ig-viral

              
Detecta conversaciones activas en Hacker News, Reddit, GitHub y nicho con evidencia real.

            

            

              02 / IDEAS & HOOKS
              
hookscore.py + beats.py

              
Aplica 26 fórmulas probadas de gancho y cronometra cada beat hablado antes de renderizar.

            

            

              03 / GOLDFISH + GATE
              
Revisión sin sesgos

              
Un subagente sin historial audita supuestos y exige aprobación explícita antes de producir.

            

            

              04 / RENDER 9:16
              
Remotion + FFmpeg + Pillow

              
Exporta MP4 H.264/AAC 1080×1920, portada 3:4 y mapa de zonas seguras para Instagram.

            

            

              05 / COPYS HUMANOS
              
ig-human + caption.py

              
Elimina huellas de IA, verifica los 125 caracteres antes del corte y limita a 5 hashtags.

            

            

              06 / PUBLICACIÓN
              
Meta Instagram Graph API

              
Verifica el paquete y sube por URL pública o subida resumable directa con registro histórico.
